# M-Hunter

M-Hunter is a modular Web Security Research Platform written in Python.

## Project Goals

M-Hunter is designed to provide:

- Reconnaissance
- Web security analysis
- API security analysis
- Vulnerability detection
- Evidence collection
- Finding analysis
- Risk classification
- Validation workflows
- Security reporting

## Status

🚧 Early Development — v0.1.0

## Platform

- Kali Linux
- Linux
- Windows
- macOS
